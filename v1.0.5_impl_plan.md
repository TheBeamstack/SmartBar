# v1.0.5_impl_plan.md — Phased build plan for the placement & detailing release

**Status:** validated against `v1.0.5_spec.md` (see **§V**). Seven phases map 1:1 onto the spec's macro-phases
**M1–M7**. Every phase **ends green** (`npm run check` + `npm run coverage` core ≥ 90 + `coverage:adapter` +
`build:web`), holds every legacy golden **except** the one intentional beam-placement re-baseline in Phase 1,
and carries the audit fixes (A1/A2/A3, B1–B4, C1–C2) folded into the spec.

> Read `v1.0.5_spec.md` first (goals, scope, invariants, owner decisions). This plan is the *task-by-task how*.
> The **UI to operate these capabilities is v1.0.6** — 1.0.5 proves the engine/model/validation/schedule/file
> headlessly and surfaces column/beam through the existing form only (spec §10).

## Global context (read once — makes the plan self-sufficient)

### Product in one paragraph
SmartBar lays out rebar inside concrete elements, gives a live 🔴/🟠/🟢 verdict, and exports BBS/DXF/PDF/`.rcfg`
— 100 % client-side. v1.0.5 turns it from a *scheme checker* into a *bar-level detailer*: any bar / shape /
position on all 8 elements, as single bars / rows / layers / bundles / skin, with per-bar curtailment, a French
façonnage schedule, and a lossless canonical file.

### Monorepo & gate
`packages/core` (pure engine — **all placement/validation/model work lives here**), `packages/codepacks`
(BAEL/EC2/RPS behind interfaces), `packages/exporters` (BBS/DXF/PDF/`.rcfg`), `apps/web` (SPA adapter + store +
UI). Gate = `npm run check` (purity → manifests → core typecheck → web typecheck → tests) + `coverage` +
`build:web`. **Node 20 / npm 10, raw-TS workspaces (no dist).**

### Non-negotiable invariants (verify EVERY phase)
1. **Engine purity** — no React/three/DOM in `packages/core`. `check:purity` green.
2. **Determinism** — pure functions; no `Date.now()`/`Math.random()` in core.
3. **No `if(elementType)` / `if(codePack)` in core** — dispatch by section (rect/circular/slab) + profile id;
   new conventions go behind `code.*`.
4. **Forward-compat** — unknown fields/kinds survive round-trip; the **new** `PLACED_BAR` kind is itself tested
   against an old reader (Phase 7).
5. **Legacy byte-identical** — every phase but Phase 1 moves **no** golden; Phase 1 moves **only** beam
   placement goldens, annotated.
6. **Live re-solve < 16 ms** — perf cases extended where a phase adds bars (Phases 2/3).

### Definition-of-Done template (every phase)
- [ ] Phase tests green; `npm run check` end-to-end green; `build:web` green; `coverage` ≥ 90 % core.
- [ ] Legacy goldens hold (except Phase 1's annotated beam re-baseline).
- [ ] End-to-end chain exercised: **core → solve → adapter → store → 3D/coupe → BBS/DXF/PDF → `.rcfg`**.
- [ ] New numeric limits sourced + flagged (§0.5); new amber band sits **below** the code value (F1 guarantee).
- [ ] `current_state.md` §1 + §9 updated; decisions ledgered.

### Engineering gates (people-dependencies, track — don't block coding)
**G-BAEL/G-EC2** — bundle equiv-Ø, skin minimum, multi-layer spacing, curtailment/anchorage constants.
**G-TOL** — new tolerance-band widths. **G-RPS** — seismic × new bars. **G-COUPE** — unchanged. Ship
`_provisional`-flagged; *code-green ≠ engineering-accepted*.

## Phase 1 — M1: Kill the placement defects (P1 + P2)  `[spec Part I]`
**Goal.** A default beam draws correct two-support top steel; the dead `continuedToSupport` fraction is gone,
replaced by per-bar curtailment + a runs-through decision. **This is the only phase that re-baselines a golden.**

**Files.** `core/section/place.ts`, `core/pipeline/element.ts`, `core/section/sectionAt.ts`,
`core/validation/profiles.ts`, `web/engine/document.ts`, `web/engine/solveDoc.ts`, `web/engine/crossTies.ts`
(migrateDoc), `web/ui/Sidebar.tsx` (minimal).

**Steps.**
1. **P1a — single placement path.** In `element.ts`, emit `longBars[]` whenever an element's faces carry >1
   longitudinal zone (beam L/R chapeaux, montage+chapeau, relevés), not only on user overrides (`:347`).
   `place.ts` already renders from `longBars` (`:176`) — remove the grouped-path top-face collapse for that case.
2. **P1b — decouple placement from validation (audit A2).** Add a pure `hasUserAddressableContent(input)` (true
   only for real user overrides / extras / rows). Gate the As/`d` reconciliation (`:596`), `placedCount`/
   `face_min_bars` (`:663`), `validateAddressableBars` (`:818`), and `richestStation` (`sectionAt.ts:446`) on
   **it**, not on `longBars !== undefined`. Verify a default beam's validation list + default coupe are unchanged.
3. **P2a — per-bar station fields (minimal, audit A1).** Add `startStation`/`endStation` + per-end `anchorage`
   (`none|straight|hook`) to `LongBarOverride`/`PlacedLongBar` (a small extension of `axisStart`). Curtailment =
   clip a bar's rendered/scheduled run to `[startStation, endStation]`; cut length follows.
4. **P2b — real end-support anchorage.** `profiles.ts` `end_support_anchorage` (`:392`) counts bars that
   actually run through to the support (geometry), dropping `continuedToSupport`/`END_SUPPORT_FRACTION`.
5. **P2c — remove + migrate the fraction.** Delete `BeamDoc.span.continuedToSupport`; `migrateDoc` maps a legacy
   `f` → the `round(f·nBottom)` innermost bars run through both supports, the rest curtail at the code cut-off
   (idempotent, at the `rcfgToDoc` chokepoint). Remove the `Sidebar` NumberField (`BeamSchemeControls:258`); add
   a minimal per-bar runs-through toggle (existing `AddressableBars` surface).

**Tests.** `tests/beam_two_support_placement.spec.ts` (default beam draws both chapeaux at correct stations with
**no** override; column/slab-main byte-identical; beam with/without an override renders the **same** top steel),
`tests/placement_validation_decouple.spec.ts` (a default multi-zone beam gains **no** addressable validation item
+ keeps its default coupe station — A2), `tests/curtailment.spec.ts` (curtailed bar shorter in placement + BBS;
runs-through drives `end_support_anchorage` from geometry; legacy `continuedToSupport` migrates).
**Flips (intentional):** beam placement goldens → annotate `# v1.0.5 P1: two-support placement (was D1)`.
**Holds:** BBS/schedule, validation-list, default-coupe, all non-beam goldens.

**DoD.** D1/D2/D3 gone; a default beam is correct with zero user edits; no dead control; only beam placement
goldens moved (annotated); everything else byte-identical.

## Phase 2 — M2: The canonical `PlacedBar` model + shared placement pass (P-A + P-B)  `[spec Track P]`
**Goal.** One first-class placed-bar unit, resolved by one shared pass wired into **all 8** pipelines.

**Files.** `core/types/` (new `placed-bar.ts`), `core/section/resolvePlacedBars.ts` (new), `core/pipeline/
{element,circular,slab,stair,joist}.ts`, `web/engine/solveDoc.ts` (+ generic inputs), `web/engine/document.ts`.

**Steps.**
1. **P-A types.** Define the `PlacedBar` family (`SingleBar` first; `BarRow`/`Bundle`/`Layer` land in Phase 3)
   with a **stable id**; generalise the Phase-1 station fields onto it.
2. **P-B extract the shared pass.** Move `buildLongBars` (`element.ts:339`) into
   `resolvePlacedBars(section, layout, placed[], code)`; `solveElement` delegates to it (behaviour-preserving —
   goldens hold).
3. **P-B section-sensitivity (audit B3).** Free/extra bars at `(u,v)` resolve section-agnostically; the
   *override-onto-existing-bar* path uses a **section-specific bar/face resolver** — RECT face+zone
   (`:361–381`), SLAB/JOIST `byZone` (`:373`), CIRCULAR pitch-circle index.
4. **P-B wire the generic shims.** Add `placed?: PlacedBarInput[]` to `Circular/Slab/Stair/JoistSolveInput`;
   each shim (which already builds a `bars[]`, e.g. `slab.ts:65`) calls the shared pass + appends `PlacedBar[]`
   to its `SolveResult`. Element-appropriate: RECT point, SLAB band level, CIRCULAR pitch-circle/interior,
   STAIR waist/landing frame.
5. **Adapter.** `solveDoc` threads `placed` for all element docs (generic docs gain a `placed?` field).

**Tests.** `tests/placed_bars_all_elements.spec.ts` (a free single bar renders + schedules + appears in the coupe
for each of the 8 elements; legacy docs byte-identical per element), `tests/resolve_placed_bars.spec.ts`
(section-agnostic free vs section-aware override resolution). Extend `perf_heavy` (dense placed set < 16 ms).
**Holds:** all goldens (no user placed bars ⇒ identical to Phase 1).

**DoD.** A free bar is placeable + fully flows on every element; the shared pass is the single long-steel truth;
legacy byte-identical.

## Phase 3 — M3: Rows, layers, bundles, skin + coupe fidelity (P-C…P-G)  `[spec Track P]`
**Goal.** The four detailer capabilities beyond single bars, each drawn faithfully in the coupe.

**Files.** `core/types/placed-bar.ts`, `core/section/resolvePlacedBars.ts`, `core/layout/rect.ts`,
`core/pipeline/element.ts` (As reconciliation), `codepacks/{bael,ec2}` (`bundleEquivDiameter`),
`core/section/sectionAt.ts` (fidelity), `web/engine/{document,solveDoc}.ts`.

**Steps.**
1. **P-C rows.** `BarRow` (anchor + count **or** spacing + one shape/Ø/curtailment) resolves to N `SingleBar`s;
   edited/persisted as one object; feeds As (weighted reconciliation already exists, `element.ts:596`).
2. **P-D layers.** Activate `RectLayout.layers`; a layer offsets `v` by `(Ø + layerGap)`; feeds area-weighted
   `d` (`computeZoneGeometryWeighted`) and between-layer clear spacing (checked in Phase 4).
3. **P-E bundles.** `Bundle` (2–4 in contact) → real schedule count (one mark), As = n·area, `code.
   bundleEquivDiameter(φ,n) = φ√n ≤ 55` (pack extra) driving cover/spacing/mandrel.
4. **P-F skin.** `BarRow` on LEFT/RIGHT faces; fold the existing SKIN supplement fanout into the row model
   (first-class, curtailable, scheduled).
5. **P-G coupe fidelity (audit C1).** Ensure `sectionAt` reads each new type at its position (bundle = n touching
   dots, layer = distinct row, skin = side-face dots, slab band / circular free bar at station); a missed bar
   correctly absent.

**Tests.** `tests/bar_row.spec.ts` (row→N scheduled; count↔spacing; As), `tests/layers.spec.ts` (2-layer lowers
`d` exactly; single-layer byte-identical), `tests/bundle.spec.ts` (count/As/φₙ), `tests/skin_steel.spec.ts`
(both faces; As to region), `tests/coupe_placed_bars.spec.ts` (each new type present/absent at the right plane).
**Holds:** all goldens (no rows/layers/bundles ⇒ identical).

**DoD.** Rows/layers/bundles/skin place, schedule, contribute to As/`d`, and render correctly in 3D **and** coupe.

## Phase 4 — M4: Validation completeness + honest tiers (Track V)  `[spec Part III]`
**Goal.** Every new kind of steel is validated with the 🔴-block / 🟠-warn split; amber bands never fire above
the code value (F1).

**Files.** `core/validation/predicates.ts`, `core/validation/profiles.ts`, `codepacks/{bael,ec2}` (limits +
band widths), `web/viewport/rebarProps.ts` (affected-bar red).

**Steps.**
1. **V-A generalise the element-agnostic predicates.** Axial-extent + in-concrete-bounds run for every element
   (envelope from its descriptor). Clear-spacing stays section-specific: rect keeps the `(u,v)` predicate;
   slab/circular reuse the per-metre / arc-spacing profile checks fed the placed bars (audit C2).
2. **V-A affected-bar id (audit B2).** `validateAddressableBars` emits the offending **placed-bar id** in
   `affectedGroupIds`; `rebarProps.ts:32–36` then reds exactly one bar.
3. **V-B bundle rules** (published): >4 (or >3 at a lap) → 🔴; φₙ cover/spacing breach → 🔴; near-limit → 🟠.
4. **V-C skin minimum** (published, depth-triggered) → 🟠 if under/absent-where-mandatory.
5. **V-D multi-layer clear spacing** (published) → 🔴 clash / 🟠 tight; `d` already recomputed (Phase 3).
6. **V-E curtailment/anchorage** (§7.7) → 🔴 short / 🟠 within band.
7. **V-F tolerance bands (bucket 2, G-TOL).** Default width per rule, flagged provisional; amber zone sits
   **below** the code value → an at-or-above-limit design is always 🟢.

**Tests.** `tests/placed_bar_validation.spec.ts` (one case per rule at 🔴/🟠/🟢; **the F1 guarantee asserted for
every new band**; the affected-bar id reds one bar). **Holds:** existing validation goldens (new items only when
real placed content exists).

**DoD.** Every new arrangement is judged honestly; a genuinely un-buildable one blocks export; a code-compliant
one never opens amber on an invented number.

## Phase 5 — M5: Splice / coupler reach (Track S)  `[spec Part IV]`
**Goal.** Piles + any free bar splice; slab distribution stays unspliced.

**Files.** `core/pipeline/circular.ts` (accept `splices`/`autoSplice`), `core/section/resolvePlacedBars.ts`
(per-bar `barSplice` on placed bars — the helper already exists for extras), `web/engine/solveDoc.ts`.

**Steps.**
1. Thread `splices?`/`autoSplice?` into the circular pipeline; splice each long zone off its `cutLength`
   (`autoSplice` at PROVISIONAL 12000 stock, `[OWNER-DEP §C]`).
2. Any `PlacedBar` carries per-bar splices; schedule as segments + coupler tally (`bbs.ts:190–224` handles it);
   `evaluateLapStagger` + seismic `lap_in_critical_zone` apply.
3. Explicitly skip slab/mesh distribution steel.

**Tests.** `tests/splice_reach.spec.ts` (pile cage auto-splits + schedules segments + couplers; a free bar
splices; slab distribution unspliced; stagger/seismic apply). **Holds:** existing splice goldens.

**DoD.** A >12 m pile cage splices in-app; free bars splice; slab distribution untouched.

## Phase 6 — M6: BAEL / French façonnage schedule (Track O)  `[spec Part V]`  `[OWNER-DEP §O-1]`

3. Verify bundles/rows/layers/curtailed bars schedule with correct count + cut (real bars, merged marks).

**Tests.** `tests/faconnage_schedule.spec.ts` (schedule renders the owner code map; a bundle/row/curtailed bar
schedules with correct count + cut; PDF/DXF agree with the on-screen BBS). **Holds:** geometry/cutLength goldens.

**DoD.** The schedule is site-ready in French façonnage; new steel schedules faithfully. *(Blocked on the owner
code table; ships provisional labels until supplied.)*

## Phase 7 — M7: Lossless canonical file (Track E)  `[spec Part VI]`
**Goal.** The `.rcfg` is faithful to a future server/IFC/other tool, not just this app — per-bar detail + seismic
+ code pack in the canonical arrays.

**Files.** `core/types/reinforcing-element.ts` (**contract extension**), `exporters/canonical.ts`,
`web/engine/rcfgDoc.ts` (`:70,77`), `exporters/rcfg.ts` (version + migration).

**Steps.**
1. **Contract extension (audit B4).** Add a `PLACED_BAR` kind (or additive `bundle`/`layer`/`stations` fields on
   `BarGroup`) — a bundle/row/layer/curtailed bar is not expressible today.
2. **canonical.ts** maps each `PlacedBar` onto it faithfully; `app_document` becomes a convenience carry, not the
   sole truth.
3. **rcfgDoc.ts** populates `seismic` + `codePack` (`:77`) from the doc; passes the store's live `result` instead
   of re-solving (`:70`).
4. **rcfg.ts** bumps `CURRENT_RCFG_VERSION` (additive, idempotent migration); forward-compat preserved.

**Tests.** `tests/interchange_lossless.spec.ts` (all 8 elements round-trip **through the canonical arrays alone**,
`app_document` stripped, with per-bar detail + seismic + codePack intact), `tests/migration_chain.spec.ts`
(extend: an **old** reader round-trips a file containing the new `PLACED_BAR` kind without dropping it —
forward-compat for our own new kind; future-version pass-through; unknown-kind survival). **Holds:** existing
migration corpus.

**DoD.** A saved file is lossless through the canonical model; no double-solve; seismic/codePack persisted;
forward-compat (incl. the new kind) tested.
