## P0.5 — Design spikes  ✅ CONFIRMED

1. **H2 leg-solver is well-posed.** All 9 open shapes default to `endHooks:{none,none}`; a user hook extension =
   `max((extFactor ?? 10)·Ø, 70)` and `bendDeductions = Σ code.bendDeduction(angle, Ø)` — both depend only on **Ø
   + angle**, never on leg length. So computing `hookAllowances`/`bendDeductions` first, then solving the named
   leg for a target `cutLength`, is correct. Linear-sum `totalLengthExpr` confirmed for all 9.
2. **H13 is adapter/UI-only.** `solveDoc` already takes `code: BaelPack = baelPack` (`:777`); threading a store
   `activePack` in and widening the type toward `CodePack` needs **no core change** (`D-P1-3`: core never imports a
   pack). `FaconnageEditor` switches from `import { baelPack }` to a `pack` prop. Signature deltas noted for the
   impl plan.
3. **H1 store guard is safe.** `withDoc` (`useStore.ts:194`) can wrap `solveDoc` in try/catch and, on throw, return
   the previous slice's `result`/`cuts` + an error flag; `defaultCoupeFor` runs on the retained good result, so the
   HUD timing + coupe re-seed are preserved. UX = non-blocking banner (P0.1 default H1.3).
