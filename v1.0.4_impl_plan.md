## Phase 1 — Stop the crash + the silent losses  (H1, H3, H4)
*Rationale: these unblock safe manual testing of everything else (spec §5.1). No new capability.*
- **H1** 🔌⚙ — `buildLongOverrides` takes the group's resolved façonnage params as fallback (not `{L:H}`); omit
  `shape` for axial-only/removed-only overrides; wrap `solveDoc` in `withDoc` with keep-last-good + a banner.
- **H3** ⚙ — add the positive-finite `cutLength` guard to `generateBarShape`; drop the duplicate editor guard.
- **H4** 🖥 — resync the editor buffer on `[shapeId, memberLength, committedKey]` with a last-committed ref.
- **Tests:** `bar_override_inherits_faconnage`, `store_solve_guard`, `cutlength_positive_guard`, `faconnage_resync`.
  **Flips:** `faconnage_p02_verify` (H1 → no-throw) + charac `[WILL-CHANGE H1]`. **Holds:** `bar_overrides`,
  `addressable_bars`, all shape goldens.
- **DoD:** the P0.2 crash repro no longer throws; a Ø-only override on a façonné group renders the group shape at
  the new Ø; core rejects `cutLength≤0` everywhere.

## Phase 2 — Valid seeds → guarded picks → length semantics  (H11, H9, H2)
*Order matters: seeds (H11) make picks (H9) safe; H2 reuses H11's `totalLengthParam` hints (spec §5.2).*
- **H11** 📄🖥 — author `default` for every open-shape param (P0.4 table); `seedParams` uses defaults, no positional
  guess; integrity test that every default shape is valid.
- **H9** 🖥 — run `pickShape`'s seed through `tryGen`; commit only if valid.
- **H2** 📄🔌🖥 `[owner H2.5]` — add `totalLengthParam` to the 9 open manifests; adapter maps `length` onto that leg
  by inverting the linear `totalLengthExpr` (P0.5 spike 1); disable the length field where no param is authored.
- **Tests:** `manifest_defaults_valid`, `pickshape_guard`, `unique_length_semantics`. **Flips:** `p02_verify`
  (H2) + charac `[WILL-CHANGE H2]`. **Holds:** `facade_shapes`, `faconnage`, `bbs_golden`.
- **DoD:** picking any shape yields a valid first sketch; `length=X` on any open shape ⇒ `cutLength==X` (±0.01).
